# Mạch integration contract

Desktop Electron app for macOS, React/Vite renderer. All timestamps epoch milliseconds; duration seconds. No automatic recording until explicit consent via settings.recording=true. Browser preview uses isolated seeded demo data and never claims actual capture.

Activity: `{id:string,title:string,url?:string,app:string,domain?:string,category:'work'|'learn'|'social'|'life',kind:'app'|'page'|'interaction',startedAt:number,duration:number,action?:'view'|'like'|'comment'|'save'|'share'|'click',bookmarked?:boolean,excerpt?:string}`.

Settings: `{recording:boolean,captureSocial:boolean,retentionDays:number,excludedDomains:string[],excludedApps:string[],focusGoalMinutes:number}`. Defaults recording=false, captureSocial=false, retentionDays=30, focusGoalMinutes=120. Browser queries/fragments stripped except exactly one valid 11-character YouTube video v ID on approved /watch hosts; no incognito, input text, passwords, screenshots or messages. A social action is an observed click, not proof of server-side success.

Renderer `window.mach`: async `getState()` returns `{events:Activity[],settings:Settings,collector:{platform:string,extensionConnected:boolean,lastExtensionSeen?:number,error?:string}}`; async `updateSettings(partial)` returns state; async `deleteEvent(id)`, `clearHistory()`, `bookmark(id,value)` return state; async `getPairingToken()` returns string; async `openExternal(url)` returns void; `onStateChanged(callback)` returns unsubscribe. API does not expose generic IPC or Node. Exports handled in renderer.

Extension local API on `http://127.0.0.1:43821`: Bearer token required on all endpoints. GET /v1/status returns `{recording,captureSocial,excludedDomains,excludedApps}`. POST /v1/events body `{events:Activity[]}` returns `{accepted:number}`. Require X-Mach-Browser (Chrome/Edge/Brave bundle ID) and X-Mach-Extension-Origin chrome-extension://[a-p]{32}; an actual Origin must match, and explicit web origins are always denied. Origin-less privileged extension requests use the declared identity plus Bearer token; bind loopback only, enforce JSON max 128 KiB and robust payload validation. Extension generates UUIDs. Heartbeat interval 15s. Page activity measured only active tab, focused browser window, user active; duration updates use same id within an uninterrupted segment, never add duplicate time; worker restarts/gaps over20s create new segment IDs. Browser foreground must be matched by desktop before accepting duration; idle/sleep excluded. Social events from explicit site permissions and user opt-in.

Build paths: renderer dist/, desktop/main.cjs, desktop/preload.cjs. Main loads dist/index.html or VITE_DEV_SERVER_URL only in development. App collection implemented by macOS helper/native API or osascript app identity polling (no window titles needed). Browser app sessions excluded from aggregate while extension connected to avoid double counts; without extension count only browser app identity. Document limits.
